# Chromaflow

一个面向绘画初学者和视觉学习者的色彩匹配练习网站。观察目标色，调整自己的颜色，再通过评分和分量差异逐步训练色感。

Chromaflow 完全在浏览器中运行，无需账号或应用后端。支持中文和英文界面，练习记录保存在本机浏览器中。

在线体验：[chromaflow.xiaotu.asia](https://chromaflow.xiaotu.asia/#/zh/)

## 功能

### 色彩匹配

- **三种调色模式**：支持 HSV、RGB、HSL，通过滑杆调整对应颜色分量。
- **色相条与色相环**：自由切换色相控制方式。HSV、HSL 使用色相环时，右侧保留另外两个分量滑杆；RGB 模式仍显示 R、G、B 三条滑杆。
- **正方形与三角形调色板**：两种形状均可搭配色相条或色相环使用，二维调色板控制 HSV 的饱和度与明度。
- **分屏与叠加对比**：并排观察两种颜色，或通过重叠区域比较差异。
- **目标色与背景色编辑**：左下角圆形色块按钮修改目标色，右下角方形色块按钮修改背景色。图标实时显示对应颜色，弹窗支持调色、随机、恢复、取消和确定。
- **分量锁定**：锁定一个或多个当前分量值，随机时仅改变未锁定分量；锁定项不可调节，切换颜色模式会清空锁定。
- **提交反馈**：显示本轮得分、颜色分量差异，以及调色控件上的目标位置提示。
- **移动端操作**：提供分量切换和加减按钮，配合滑杆与调色板使用。

### 图片取色

选择本地图片后，自动提取一组代表色，用作练习目标；也可以打开编辑弹窗调整提取的颜色。

图片通过浏览器本地读取和处理，不会上传到服务器，也不会写入练习历史。

### 练习历史

- 每次提交后自动保存，最多保留最近 **50 次**练习。
- 查看目标色、匹配色、提交模式、日期和得分。
- 按 HSV、RGB、HSL 提交模式筛选，分页浏览记录。
- 显示已保存次数及全部已保存记录的平均分，平均分保留 **两位小数**。
- 下载 CSV 或清空本机记录。
- 重新进入练习页时，恢复最近一次提交的颜色、模式与结果。

### 色彩知识库

提供中英文文章，涵盖色彩基础、光与颜料、冷暖与空间、色彩心理、配色关系和中性色。文章以 Markdown 文件维护。

## 如何练习

1. 打开「练习」，选择 HSV、RGB 或 HSL 模式。
2. 观察左侧目标色，通过右侧滑杆、调色板或色相环调整预览色。
3. 点击「提交」，查看得分与差异提示。
4. 点击「下一题」或单击目标色圆圈，生成新的目标色。需要指定颜色时，使用左下角编辑按钮，也可双击目标色圆圈。
5. 到「练习历史」回顾结果，或下载记录。

### 评分说明

评分范围为 0–100，基于 HSV 分量差异计算：色相按色环最短距离比较，并与饱和度、明度差异加权计算。切换调色模式不会切换评分算法。

评分用于练习反馈，不是专业色差测量。

## 本地运行

环境要求：Node.js `22.12+` 和 npm。

在项目根目录运行：

```sh
npm ci
npm run dev
```

开发服务器默认监听 `http://127.0.0.1:3000`，实际地址以终端输出为准。

| 页面 | 中文路径 |
| --- | --- |
| 首页 | `/#/zh/` |
| 练习 | `/#/zh/practice` |
| 练习历史 | `/#/zh/profile` |
| 知识库 | `/#/zh/knowledge-base` |

将路径中的 `zh` 换成 `en` 即可访问英文页面。

### 技术栈

React 19、TypeScript 5、Vite 7、Tailwind CSS 3、React Router 7（HashRouter），使用 Lucide 图标、Color Thief 提取图片颜色、Marked 渲染知识库文章。

## 数据保存与导出

练习记录使用浏览器 `localStorage`。每条记录包含标识、提交时间、提交模式、目标色和匹配色，颜色以 HSV 保存；展示和导出时按当前算法重新计算得分。

记录按提交时间由新到旧保存，超过 50 条时移除最早的记录。历史只属于当前浏览器、当前站点来源，不支持跨设备同步；更换协议、域名、端口或浏览器后不会共享。清除站点数据会删除记录。

CSV 导出全部已保存记录，包含时间、模式、得分及两组 HSV 数值，可用于表格分析和留存。当前没有 CSV 导入或恢复功能。

未提交的调色状态、上传图片、背景色、锁定项和调色视图设置不随练习记录保存。
